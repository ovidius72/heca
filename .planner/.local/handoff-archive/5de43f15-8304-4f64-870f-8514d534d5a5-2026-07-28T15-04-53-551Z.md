## Recent decisions (all 2026-07-29/30, all in the phase's decision table)

- **Widgets answer gestures; components declare semantics.** Scroll, wheel, click, drag are the
  widget's — nothing is declared for them. What a component declares is what its *selection* means.
- **No generic verb set.** A dock showing one number has no up/down; inherited verbs would be dead
  weight. Conventional ids encouraged, never enforced.
- **Focus is the mode** — no `InputMode` variant beside it.
- **Unbound key while a component is focused → swallowed**; **prefix falls through** to the
  component's layer when the global map misses.
- **`perform(id, args, cx)`**, not one closure per action — it is the shape a WASM component is
  forced into, keeps `&self`, and `ProviderCx` enforces §2.3 (a `DynHandler` would hand a component
  `&mut AppState`).
- **`kind()` (type → bindings, actions) is distinct from `id()` (mount → cursor, scroll, focus)**.
- **`nav_key` is a row's ONE identity** — cursor, right-click target, later drag.
- `[keys.<kind>]` is a table (merges per key); `[[…bind]]` merges by `keys`; removal via an explicit
  `unbind`, never null/empty-string.
- T012's prefix-gated scroll keys are **superseded**: plain `PageUp/PageDown/Home/End` while a
  component is focused; `Shift+` variants unchanged for the pane.
