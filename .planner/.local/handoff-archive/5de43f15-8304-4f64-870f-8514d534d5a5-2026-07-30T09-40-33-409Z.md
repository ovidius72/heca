## Gotchas that cost time this session

- **`WorkspacesContainerState::tree()` is a `RefCell`.** End the borrow before any call that reaches
  back into the store, or it panics at runtime rather than failing to compile. Four borrows had to be
  shortened; expect more when step 3 moves handlers in.
- **`publish_sidebar_selection` → `selection_nav_key` is a deliberate single bridge** between the old
  domain-typed selection and the generic cursor. It exists so there is exactly one place to delete in
  step 5. Do not add a second.
- **BSD `sed` has no `\b`** — use Python for word-boundary renames.
- **`every_glyph_name_has_a_mirror`** (in `heca-view-realize`) fails if a `Glyph` is added without
  mirroring it into `heca-view`'s `ViewGlyph`. It caught exactly that this session.
- `CaretLeft`'s codepoint `0xe138` is **inferred** from Phosphor's alphabetical layout — confirm in
  the showcase glyph grid, as `CaretUp` already asks.
- Do not run `cargo fmt` (repo rule). Rust skill review → clippy → commit, and wait for the user's
  approval to commit.
