Button::shortcut(char) → composed Icon(NfIcon ⌃)+Label(letter) trailing slot inside the button; Ctrl+<c> self-submit + FocusManager::deliver_accelerator. Blocked on viewnode-all-widgets (Button) + gridui-03 NerdFont.

Give a `Button` an explicit **accelerator** (`Ctrl+<letter>`) rendered **inside** the button as composed content, and wire it through the confirm/modal builders.

## STATUS: UNBLOCKED on the Button side (2026-07-13)
The blocker is gone: `Button` now **composes its content from children** (commit `07d4c1a`, PR #237) — it holds an arbitrary child tree and the size variant + state color cascade into it. So the accelerator is just **another child**, exactly as the design demands. Still blocked on **NerdFont embedding** (`gridui-03`) for the glyph.

## DESIGN LOCKED (user, rescued from the old root HANDOFF.md §2/§3b — do NOT relitigate)
- **Trigger: `Ctrl+<letter>`.** Chosen because it works in **confirm AND form dialogs** — a bare letter would collide with typing in an `Input`.
- **Rendered INSIDE the button**, as a **composed `Icon + Label`** child (the letter next to a control glyph). **NOT** hand-drawn `cx.icon`/`cx.text`, **NOT** placed adjacent to/outside the button. With the composition refactor landed, this is now natural: `.shortcut(c)` is **sugar that appends a child**, the same way `.icon(g)` prepends one.
- **The Button self-submits on `Ctrl+<c>`**; a host helper (`FocusManager::deliver_accelerator`) routes the accelerator to the matching **non-focused** button (otherwise only the focused button could be triggered).
- **`ModalAction.shortcut: Option<char>`**, set by the confirm builder. The **letter is semantic** — `n` = cancel/negative, `y` = confirm/positive — and must be assigned by the **caller/builder**, because a widget cannot infer that "Cancel" means "No".
- **Glyph: NerdFont, NOT Phosphor.** `Glyph::CaretUp` (codepoint `0xe13c`) was added for this and the user judged Phosphor's caret **ugly**. It **stays in the enum** (user directive: *keep it, do not remove*) but the accelerator uses a NerdFont control glyph instead.
