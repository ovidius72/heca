## DESIGN LOCKED (grill-me 2026-07-13 with user — do NOT re-derive)
- **Children, not slots.** `Button` holds `children: Vec<Box<dyn Component>>` — arbitrary tree, any depth. `Parent` (`.child`), plus `.content_boxed(Box<dyn Component>)` for a `realize`d subtree (`Dialog::body_boxed` precedent). The `label` field is GONE.
- **Sugar desugars into children at build time** (no second paint path): `Button::new("X")` -> `[Label bold]`; `.icon(g)` -> prepends `[Icon, Label]`; `Button::empty()` -> compose freely. ViewNode precedence: **children win**; `text`/`icon` props build the sugar only when childless.
- **Widget stops computing size; taffy measures.** `width`/`height` = `Auto`; `padding_x = BASE_PAD*pad_scale + fs*MONO_ADVANCE_RATIO` (one char/side), `padding_y = BASE_PAD*pad_scale`, `gap = fs*0.5`. Exact parity with the old `(chars+2)*fs*ratio + pad*2`.
- **Per-state content color = ONE inherited `Color`** via `PaintCx::with_content_color`. Parent can't set child colors (children are `impl Component`; `Theme` only exists in `paint`), so it publishes one value per frame and unstyled `Label`/`Icon` pull it -> content animates with hover / fades when disabled, zero per-child wiring. Explicit `.color()` and intrinsic-color widgets (`Badge::danger`) win.
- **One control = one Tab stop**: `Base.focus_barrier` stops focus descent (`focus.rs` `for_each_focusable`). Set by `Button` + `Item`.
- **Size variant now INHERITS down the tree** (approved library change) — the missing piece that made composition actually work.
