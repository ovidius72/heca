### 📋 23ae642e-96c1-4bb0-a4a1-c5a1adfe7567 — T294 — Focus follows mouse delay

Status: 📋 `planned`

APERTO — punto 4 della lista finale di `redo-mouse.md` (file cancellato 2026-07-14; contenuto verificato e migrato qui).
Testo originale: "Add `focus_follows_mouse_delay_ms` config".

## PERCHÉ
Con `focus_follows_mouse = true`, il focus segue il cursore ISTANTANEAMENTE: attraversare una pane per raggiungerne un'altra ruba il focus alle pane intermedie (il classico "focus flicker" mentre si muove il mouse in diagonale). Un ritardo (hover dwell) prima di cambiare focus lo elimina: il focus cambia solo se il cursore RESTA sulla pane per N ms.

## STATO (verificato 2026-07-14)
- `focus_follows_mouse` ESISTE: setting in `heca-config` `[settings]`, letto sul `CursorMoved` in `heca/src/mouse.rs` (gate: `mouse_enabled` + `focus_follows_mouse` + `InputMode::Normal|Prefix` + cursore nell'area contenuto, poi `hit_test_pane`).
- **`focus_follows_mouse_delay_ms` NON esiste**: zero occorrenze in tutto il repo (`--include=*.rs --include=*.toml`). Mai implementato.

## LAVORO
1. `heca-config/src/settings.rs`: nuovo campo `focus_follows_mouse_delay_ms: u64` (0 = comportamento odierno, istantaneo → back-compat totale).
2. **`config.default.toml`**: aggiungere il setting con commento sotto `[settings]` (regola cardinale AGENTS.md: un campo di `SettingsConfig` che non sta nel file di default è un BUG — il default vivrebbe solo nel codice, invisibile all'utente).
3. `heca/src/mouse.rs` (`CursorMoved`): non cambiare focus subito. Registrare pane candidata + istante; il focus scatta quando il cursore è rimasto sulla STESSA pane per `delay_ms`. Se il cursore passa su un'altra pane prima della scadenza, il timer riparte. NB: serve un tick (l'`about_to_wait`/loop di redraw già esiste — lì gira anche `dnd_edge_scroll`), altrimenti senza ulteriori eventi mouse il focus non scatterebbe mai.
4. Il cambio di focus DEVE passare dall'azione (`WmAction::FocusPane` via il dispatch centrale), non da una mutazione diretta.
5. Reload a runtime (`prefix+Shift+r`) deve raccogliere il nuovo valore.
6. `README.md`: documentare il setting.

## TEST
- delay = 0 → comportamento identico a oggi (test di non-regressione);
- delay > 0 → attraversare una pane senza fermarsi NON le dà il focus;
- restare fermi oltre la soglia → il focus cambia una volta sola;
- il timer si resetta cambiando pane.
