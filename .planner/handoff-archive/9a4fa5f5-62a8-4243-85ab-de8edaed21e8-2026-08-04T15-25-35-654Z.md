## 🔴 Next: T393 — the palette opens in a mode

**Read the task in full: every decision is settled and written there.** The short version:

| Decision | Value |
|---|---|
| Sigils | `:` actions (default), `@` panes, `$` workspaces |
| Action | `command_palette` gains optional `mode` **and** `query` |
| Pane rank id | display name (`custom_name` else `title`) |
| Workspace rank id | its `name`; **no id** when unnamed |
| Auto-submit | **No** — a binding whose behaviour drifts with your habits |
| Ranking ephemeral rows | **Yes**, it is safe |

The one design insight worth not losing: **`mode` and `query` compose into a prefilled query.**
`mode=pane query=nvim` opens the palette with `"@nvim"`. The sigil *is* the mode selector, so the
widget needs no "open in mode" API and the app needs no second mechanism.

The second: **keep one flat `commands` list** and treat the mode as a filter. Row text children are
built one per command and indexed by position, so per-mode lists would mean re-indexing children on
every switch.

`PaneId`/`WorkspaceId` are unusable as rank ids — the counter restarts at 1 each launch
(`heca-core/src/layout/session.rs:81`) and workspace indices are reused, so a persisted count would
attach to a *different* pane or workspace. That is why the ids are names.

## Facts worth not rediscovering

- **The SDK drift guard demands a builder for every `#[prop]`** (`heca-view-realize`'s
  `every_widget_property_is_reachable_from_the_sdk`); fix by adding one in `heca-view/src/build.rs`.
  A `host_only` prop (a list, a composed value) is exempt. It fired for `wrap`, `mark_color`,
  `muted`. `u8` is **not** an accepted prop type; `u16`/`usize`/`f32` are.
- **A label inside a `Flex` resolves to font 13.5, not 15** (size-variant scaling). A test that
  hardcodes 15 to compute the monospace cell measures the box a character wide and will accuse
  correct code of overflowing. Read `base().font` *after* layout.
- **Taffy rounds every box to whole pixels.** A label measured at its natural 105.3px is handed
  105.0 — and a label that cannot fit its own text cuts it. `mono_cells` carries a half-pixel slack
  for exactly this; the old `1e-6` only covered f64 division error.
- **The shaper drops a text run's leading whitespace.** Splitting a line into runs at mark
  boundaries walks every space in the label. Marks are over-drawn per character for this reason.
  Scene-level tests cannot see it — the runs they assert are correct and the loss is in shaping.
- **Overlay layers are laid out every frame** — `heca/src/chrome/mod.rs:2285` `layout_layers` runs
  `LayoutEngine::compute` on each visible layer root. Layer children get real measured bounds.
- **`Select` is the precedent for an overlay with real children** (`select.rs:188`, `:365`, `:554`):
  measured in the widget's own flow, then shifted to absolute targets in the panel.
- **Clearing cannot just empty the store** — the next save merges the disk back in.
  `search_state::forget` rewrites the file instead.
- **`forget_on_disk` is split from `forget`** only because `forget` takes `&mut AppState`, which
  cannot exist in a test (it needs a window).
- Handoffs live on `phase.handoff`; `.planner/HANDOFF.md` is deprecated. `resume.json`'s `nextSteps`
  are stale free text — read the task.
- `planner-task-complete` fails on an unticked checklist; `force: true` is the way when the work
  shipped without the checklist being ticked. **Check task status against the commits** — three
  finished tasks sat `in-progress` this session and the user caught each one.
