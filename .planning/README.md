# .planning — historical archive

The files in this folder come from the planning tool heca used before the current planner. They
are **kept for reference only and are not maintained**: statuses, roadmaps and requirements here
are out of date, and nothing in this folder is a source of truth.

- Current work, decisions and open items: the project planner (`.planner/`, loaded with
  `/planner load`). Everything still open here was carried into it on 2026-11-16.
- How heca works: [`docs/`](../docs/README.md).
