# Gestures

> Touchpad, mouse, and drag-and-drop gesture reference.

## Mouse Gestures

| Gesture | Action |
|---------|--------|
| Mod + left button drag | Interactive move window |
| Mod + right button drag | Interactive resize window |
| Mod + middle button drag (horizontal) | Horizontal view movement |
| Mod + middle button drag (vertical) | Workspace switch |
| Right-click during move | Toggle floating/tiling |
| Double-click top/bottom resize edge | Reset window height to auto |
| Double-click left/right resize edge | Expand column to full width |

## Touchpad Gestures

| Gesture | Action |
|---------|--------|
| 3-finger vertical swipe | Switch workspace |
| 3-finger horizontal swipe | Horizontal view movement |
| 4-finger vertical swipe | Open/close overview (since 25.05) |

## Drag-and-Drop

Since 25.02. Standard DnD (file from file manager, etc.):

- Move cursor against monitor edge → scroll tiling view
- In overview: move cursor against edge → switch workspaces (since 25.05)
- Hover over window → activate it / bring float to front (since 25.05)
- In overview: hover over workspace → switch to it

## Hot Corner

Since 25.05. Top-left monitor corner → toggle overview. Configurable.
