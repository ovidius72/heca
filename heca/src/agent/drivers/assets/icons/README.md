# Harness marks

Claude and Codex: the `claude-color.svg` and `codex-color.svg` variants from
[Lobe Icons](https://github.com/lobehub/lobe-icons/tree/ab8cbcc6ce806b923c547628132957c8a8b61509/packages/static-svg/icons), MIT (LOBE-LICENSE).
OpenCode: the dark-surface mark from its official
[brand assets](https://github.com/anomalyco/opencode/blob/cdf1c200a671378458b50f9e3167405f1f326b24/packages/console/app/src/asset/brand/opencode-logo-dark.svg), MIT (OPENCODE-LICENSE).
Pi: [official logo](https://pi.dev/logo-auto.svg), linked by the
[Pi repository](https://github.com/earendil-works/pi), MIT (PI-LICENSE).
Pi's viewBox is cropped to the existing paths so its mark fills the same icon box.
The Codex app tile is removed and its viewBox cropped to the existing gradient mark,
so it sits on the same transparent background as the other harness marks.

Brand fills live in the SVG files. The shared Image widget preserves them;
these marks do not inherit the row's text color. Users may override an integration's
icon with a local image, including a different light/dark brand variant.

The marks identify their respective programs. Trademarks belong to their owners.
